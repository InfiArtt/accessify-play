# Play from URL

This feature allows you to instantly play any Spotify content if you have its Spotify link (URL). This is useful if you copy a link from the web or receive a recommendation from a friend.

## How to Use

1.  Open the **Play from Link** dialog (default shortcut `U` in Command Layer).
2.  **Paste Link:** In the first text box, paste (CTRL+V) the Spotify URL you have.
    *   Example URL: `https://open.spotify.com/track/4n7jnSxVLd8QioibtTDBDq`
3.  **Check Link:** Press the `Check` button. Accessify Play will verify the link and fetch information about the target song, album, or playlist.
4.  **Review Details:** Information about the content (Title, Artist, Type) will appear in the read-only text box. Ensure this is the correct content.
5.  **Play:** Once details are loaded and verified, the `Play` button will become active. Press it to start listening.

## Tips

*   This feature supports various Spotify link types, including Tracks, Albums, Playlists, Artists, and Shows.
*   If the link is invalid, an error message will be displayed in the details box.
