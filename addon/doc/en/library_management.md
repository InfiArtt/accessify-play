# Library

Open the Library with `NVDA+Alt+G` then `M`. It opens straight away, and each tab loads its list the first time you open it, saying "Loading..." meanwhile. Switch tabs with `Ctrl+Tab`.

## Shortcuts

These work in every tab:

| Shortcut | Action |
| :------- | :----- |
| `Enter` | The main action for the item (see each tab) |
| `Alt+P` | Play |
| `Alt+Q` | Add to queue |
| `Alt+L` | Copy the Spotify link |
| `Alt+R` | Refresh the current tab |
| `Ctrl+N` | Create a new playlist |
| Applications key or `Shift+F10` | Context menu with more options |

## Tabs

### Manage Playlists

Choose a playlist in the **Playlist** box; its tracks appear in the list below. Each playlist is marked "Owned by You" or with the name of its owner.

* `Enter` on a track plays the playlist from that track.
* **Play Playlist** plays the whole playlist.
* **Refresh Playlists** reloads your playlists and stays on the playlist and track you were on.
* **Edit Playlist Details**: change the name, description, and whether it is public or collaborative.
* **Delete Playlist** (your own) or **Unfollow Playlist** (someone else's), after asking you.
* **Remove Duplicates** removes extra copies of tracks that appear more than once, keeping the first copy of each. It tells you how many it found and asks before removing anything.
* **Clear Playlist** removes every track but keeps the playlist itself, after asking you.

In a playlist you own, you can also rearrange tracks:

* `Alt+Up Arrow` and `Alt+Down Arrow` move the selected track up or down.
* `Delete` removes the selected track, after asking you. If the same song is in the playlist more than once, only the copy you selected is removed.

The track context menu also has Remove Track from Playlist, Remove Duplicates, Show Lyrics, Go to Album and Go to Artist.

**Creating a playlist:** press `Ctrl+N`, enter a name and, if you like, a description, and choose whether it is public. A collaborative playlist must be private.

### Saved Tracks

Your Liked Songs. `Enter` plays a song. The context menu has Remove from Library, Add to Playlist, Show Lyrics, Go to Album and Go to Artist.

### Saved Albums

`Enter` opens an album's tracks. The context menu has View Album Tracks and Remove from Library.

### Followed Artists

`Enter` opens an artist's discography. The context menu has View Discography and Unfollow.

### Top Items

Your most-played tracks or artists. Choose **Top Tracks** or **Top Artists** in **Show**, and Last 4 Weeks, Last 6 Months or All Time in **Time Range**; the list updates as you change them. `Enter` plays the item, and for an artist the context menu has View Discography.

### Saved Shows

The podcasts you follow. `Enter` opens a show's episodes. The context menu has View Episodes and Remove from Library.

### Saved Episodes

Episodes you saved to listen to later, showing the episode, its show and its release date. `Enter` plays an episode. The context menu has View All Episodes of (the show), which opens that podcast's full episode list, and Remove from Library.

### Saved Audiobooks

`Enter` opens a book's chapters. The context menu has View Chapters and Remove from Library.

### New Releases

Recent albums and singles. `Enter` plays an album. The context menu has View Discography, View Album Tracks and Add Album to Playlist. Spotify has announced that it will retire New Releases; if it does, the tab says so.

### Recently Played

What you listened to recently. `Enter` plays a track. The context menu has Add to Playlist, Show Lyrics, Go to Album and Go to Artist.

## Adding the current track to a playlist

Without opening the Library: press `NVDA+Alt+G` then `A`, choose one of your playlists and press **Add to Playlist**. If the track is already in that playlist, you are told so instead.
