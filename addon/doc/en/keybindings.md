# Command keys

Press **`NVDA+Alt+G`** to open the command layer, then press one of the keys below. This is the add-on's only default shortcut.

* `F1` lists every key, so you don't need to memorize them.
* `Escape` closes the layer without doing anything.
* A key that isn't in the layer closes it with a low beep.
* Some commands keep the layer open, so you can press them again straight away (for example `N` several times to skip several tracks). These are marked "stays open" below. Press `Escape` when you are done. You can choose which commands stay open: see [Customizing the command layer](customizing_commands.html).
* If you leave the layer open and don't press anything for 30 seconds, the next key you press closes it and works as normal instead.

## Playback

| Key | Command |
| :-- | :------ |
| `P` | Play or pause |
| `N` | Next track (stays open) |
| `B` | Previous track (stays open) |
| `=` | Volume up (stays open) |
| `-` | Volume down (stays open) |
| `V` | Set the volume to a percentage |
| `]` | Seek forward (stays open) |
| `[` | Seek backward (stays open) |
| `J` | Seek to a time, or jump forward or back |
| `H` | Shuffle on or off |
| `R` | Repeat: all, one track, off (stays open) |
| `G` | Play your top tracks of the last month |
| `O` | Play your recently played tracks |
| `D` | Choose the device to play on |

## Information

| Key | Command |
| :-- | :------ |
| `I` | Announce the current track |
| `T` | Announce the playback time |
| `E` | Announce the next track in the queue |
| `Q` | Open the queue |

## Library and sharing

| Key | Command |
| :-- | :------ |
| `L` | Like or unlike the current track (stays open) |
| `F` | Follow or unfollow the current track's artist |
| `A` | Add the current track to one of your playlists |
| `M` | Open the Library |
| `S` | Open Search |
| `U` | Play from a Spotify link |
| `C` | Copy the current track's Spotify link |
| `X` | Copy a Song.link link to the current track |

## Lyrics

| Key | Command |
| :-- | :------ |
| `W` | Open the lyrics window |
| `Y` | Automatic lyric reading on or off |

## Other

| Key | Command |
| :-- | :------ |
| `Z` | Sleep timer |
| `F4` | Accessify Play settings |
| `F1` | List the command layer keys |
| `F2` | Edit the command layer keys |
| `Escape` | Close the command layer |

## Shortcuts outside the layer

Every command above (except `F1`, `F2` and `Escape`) is also listed in NVDA's Input Gestures dialog (NVDA menu, Preferences, Input Gestures), under **Accessify Play**. Assign a gesture there to run a command directly, without opening the layer first.
