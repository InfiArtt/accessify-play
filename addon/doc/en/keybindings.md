# Accessify Play Command Keys

This section focuses on command keys for controlling Spotify using Accessify Play. Accessify Play can be controlled via the Command Layer. Activate the Command Layer by pressing **NVDA+G**, then press one of the following keys:

[Want to change these keys? Read the customization guide in customizing_commands.html](customizing_commands.html)

## **Playback Control**

- **P**: Play or pause the current track on Spotify.
- **N**: Skip to the next track on Spotify.
- **B**: Skip to the previous track on Spotify.
- **-**: Decrease Spotify volume.
- **=**: Increase Spotify volume.
- **V**: Set Spotify volume to a specific percentage.
- **[**: Rewind within the current track.
- **]**: Fast forward within the current track.
- **J**: Jump to a specific time or seek forward/backward.
- **U**: Play an item from a Spotify URL.

## **Announcements**

- **I**: Announce the currently playing track.
- **T**: Announce the playback time of the current track.
- **E**: Announce the next track in the queue.

## **Miscellaneous**

- **H**: Toggle Shuffle mode.
- **R**: Change Repeat mode (Off, Context, Track).
- **F**: Follow or unfollow the artist of the current track.
- **A**: Add the currently playing track to a playlist.
- **C**: Copy the URL of the current track.
- **D**: Show available devices to switch playback.
- **L**: Like/Unlike Track.
- **M**: Manage your Spotify library and playlists.
- **Q**: Show the Spotify queue list.
- **S**: Search for an item on Spotify.
- **X**: Copy Universal URL (Song.link).
- **Z**: Set Sleep Timer.
- **F4**: Open Accessify Play settings.
- **F1**: Show layered command help.
- **F2**: Show layered command editor.
- **Esc (Escape)**: Close the Command Layer.
