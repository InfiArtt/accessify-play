# Queue Dialog

The Queue Dialog (`Q` in Command Layer) allows you to view and manage the sequence of upcoming tracks.

## Key Features

*   **Queue List:** Displays the currently playing song (marked "Playing") and the list of upcoming "Queue" tracks.
*   **Navigation:** Use Up/Down arrows to browse the list.
*   **Jump to Track:** Press `Enter` on any track to immediately skip to that song.
*   **Refresh:** Sometimes the queue changes in the background. Press the `Refresh` button (`Alt+R`) to ensure you are viewing the latest list.

## Keyboard Shortcuts

*   `Alt+P`: Play selected item (Same as Enter).
*   `Alt+L`: Copy Link of the selected track.
*   `Alt+R`: Refresh the queue list.
